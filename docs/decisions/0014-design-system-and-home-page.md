# 0014 — Design system and marketing home page

**Status:** Accepted (Phase 1).

## Design system: "Regal Modernity"

The Google Stitch design system "Regal Modernity" (Stitch project `11709379677369700007`) is
the shared visual foundation for every screen, including later authenticated screens. Pages
do not define their own visual language.

| Token          | Value                                |
| -------------- | ------------------------------------ |
| Midnight Navy  | `#0A1128`                            |
| Champagne Gold | `#C5A880`                            |
| Muted Sage     | `#76877D`                            |
| Warm Ivory     | `#FAF8F5`                            |
| Headings       | Playfair Display (selected headings) |
| Body and UI    | Plus Jakarta Sans                    |

- Tokens live in `apps/web/src/app/globals.css` (Tailwind `@theme`). Alongside the four brand
  colours, the theme carries the role palette Stitch derives from them (`surface`,
  `on-surface-variant`, `secondary`, …), because the approved screens are rendered with it.
- Fonts are self-hosted by `next/font` at build time.
- Icons are Material Symbols Outlined (Apache-2.0), shipped as inline SVG paths generated by
  `apps/web/scripts/generate-icons.mjs` — no icon font.
- The approved logo is inlined in `components/ui/logo.tsx` with its geometry and colours
  unchanged; the favicon uses the logo mark.

## Home page

- **Source:** Stitch screen "Premium Modern Indian Wedding Platform (V1 Approved)", with the
  final copy corrections approved on 2026-10-01 (Ceremony 01 card, "Guests & Invitations",
  per-event RSVP wording, "Email invitations · WhatsApp share link", dress-code text,
  "6 vendors · 3 confirmed", Haldi notes). The copy is final.
- **Scope rule:** the page describes V1 exactly as the PRD defines it. It does not advertise
  capabilities outside the PRD, social proof, pricing, legal-entity names, security or
  compliance mechanisms that are not implemented, or public destinations that do not exist.
  Live streaming is named as YouTube Live. Footer: "© 2026 MakeMyMarriage. All rights reserved."
- **Enforcement:** all copy and mock-up data live in
  `apps/web/src/features/marketing/home/content.ts`; `content.spec.ts` fails CI if an
  out-of-scope claim reappears.
- **Mock-ups:** people, venues and amounts in illustrations are fictional sample data.
- **Responsive layout:** desktop follows the design. Tablet and mobile layouts are designed in
  code with the same system (the Stitch designs are desktop-only); below 1024px the navigation
  collapses into a menu that keeps "Create Your Wedding" and "Sign In".

## Assets and external dependencies

- The two home page photos are Stitch-generated and stored in
  `apps/web/public/images/home/`. They are approved for the current development and design
  phase; **usage rights for the public launch must be confirmed before launch.**
- At runtime the page loads nothing from third parties: fonts, images and icons are all served
  by the web app. Only the build downloads the Google Fonts files (via `next/font`).
