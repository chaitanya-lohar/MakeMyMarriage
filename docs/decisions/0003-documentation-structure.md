# 0003 — Repository documentation structure

**Status:** Accepted (decision A3)

- `docs/specs/` — approved product and technical specifications (PRD, System Design,
  Database Design, API Design), kept with their version in the file name.
- `docs/decisions/` — decision records such as this one.

Specifications are historical records. They are not rewritten to match later decisions
or to simplify implementation. When a specification is stale or conflicts with a later
decision, the resolution is recorded here and names the superseded statement.

The GitHub repository is private.
